What I built

A game studio staffed by AI agents

Since September I've been building a studio that makes small skill games: 30 to 60 seconds each, playable with one thumb. AI agents write them. I set the rules and approve what ships.

Six games exist today: a cave flyer, a shape tracer, a block placement puzzle, a swipe-timing game, a tap-timing game and a pressure-hold game. Every one runs on the same contract, and every one is deterministic: the same starting seed always produces the same round, so any score can be replayed and checked.

How it works

Let AI produce a lot. Check all of it. Keep the human for the calls only a human should make.

  1. AI agents buildThe strongest model designs. A cheaper one builds. The cheapest does the mechanical work. Each job goes to the least expensive model that can do it.
  2. Five automated gatesA banned-code scan, a size limit, a same-seed-same-result check, a valid-score check and a start-to-finish run. A game that fails any one goes back.
  3. Bots play itBots of different skill play the same seeded rounds. If the better bot doesn't reliably win, the game isn't measuring skill, and it's rejected.
  4. I approveAgents can propose a change. Only a person can accept it.
  5. It ships, and the log growsEvery shipped thing gets a line in the Proof Log at the bottom of this page.
The rulebook sits outside the AI's reach.

One contract that every game must satisfy, plus 23 written decisions, each tagged with how hard it would be to undo. A guard blocks the agents from editing either one, and 7 tests make sure the guard keeps working.

Case study #1

Client Zero: I was my own first client

The problem

I needed a lot of small games, each one fair, and I'm one person. AI can write code quickly. It can also be confidently wrong. Building each game by hand was too slow, and trusting unchecked AI output was not an option.

What I built

A studio with a written definition of done, automated gates, bot players that test whether skill matters, model routing that keeps cost down, a decision log, and one rule that never bends: an agent can propose, and only a person can approve.
